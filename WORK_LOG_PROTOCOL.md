# Work Log Protocol

## Non-Negotiable Rules

Every work session MUST follow these rules. No exceptions.

### 1. Session Start
- Read `memory/` latest daily file and `MEMORY.md`
- Create today's daily file: `memory/YYYY-MM-DD.md`
- Log: what task was assigned, what the goal is

### 2. Every 5 Minutes / Every Milestone (whichever is sooner)
- Update the daily file with:
  - What was just completed
  - What's being worked on next
  - Any blockers or decisions made
  - File paths created/modified

### 3. Project-Level Context
- Every project folder MUST have a `PROGRESS.md` with:
  - Current status
  - What's done
  - What's in progress
  - What's next
  - Last updated timestamp

### 4. Session End / Before Any Break
- Final update to daily file
- Update project `PROGRESS.md`
- Update `MEMORY.md` if anything significant happened

### 5. If Timeout/Crash Recovery
- The daily file and PROGRESS.md serve as recovery points
- Next session can pick up exactly where things left off

## Why This Exists

Because on 2026-07-19 we lost an entire day of work context due to no notes being saved during a long session. 4M context window burned with nothing to show for continuity. Never again.
