# Industry & concept playbooks: visual DIRECTION, not templates

This file gives each industry a visual *compass*, not a stencil. The goal is the opposite of "every deck looks the same": two fintech decks should feel like fintech **and** look clearly different from each other.

## How to use this file

1. You've already picked a persona from the Style Router in SKILL.md.
2. Find the matching playbook below and read its DNA — palette logic, type feel, motif idea, layout rhythm, imagery, and the domain-specific anti-patterns.
3. **Treat every value as a direction, never a fixed recipe.** The palette logic says "dark + one moody accent" — YOU choose which accent, which dark, which font. A climate deck and a fintech deck can both be "dark + one accent" yet look nothing alike.
4. Apply the **variation rule** at the bottom of each playbook so repeat decks in the same industry diverge.

### The one rule above all others
> A playbook tells you the *grammar* of an industry's visual language. It never writes the sentence for you. If two decks you build for the same industry could be swapped without anyone noticing, you used the playbook as a template instead of a compass — that's a failure.

## Fintech / Crypto / Payments

- **Palette logic:** Dark, confident base (off-black, deep navy, near-black plum) + exactly ONE moody accent (electric teal, gold, signal orange, lime). Trust through restraint, not corporate blue.
- **Type feel:** Geometric or grotesque display (Neue Haas Grotesk Display Pro, Space Grotesk, Bricolage Grotesque) + a clean neutral body. Heavy display weight against light body.
- **Motif idea:** Precision lines, ticker-style numerals, a single sharp diagonal, monospace data tags. Pick ONE.
- **Layout rhythm:** Generous negative space. Big numbers as heroes. Dense data slides balanced by sparse statement slides.
- **Imagery:** Abstract data/network viz, macro textures (brushed metal, glass), never literal "person holding phone".
- **Anti-patterns (fintech-specific):** Purple-blue SaaS gradient, neon glow everywhere, stock "businessperson at laptop", coin clipart for crypto.
- **Vary by:** Swap the accent hue + the motif. Deck A = gold + diagonal slash; Deck B = electric teal + monospace tags. Both read fintech, neither looks alike.

## SaaS / Developer tools / B2B software

- **Palette logic:** Either confident dark (product-led, technical) OR clean light with one strong primary (sales-led). Pick the lane and commit.
- **Type feel:** Modern neutral (Inter, Manrope, Neue Haas Grotesk Display Pro) with real weight contrast. Mono accents for anything code/data.
- **Motif idea:** Grid lines, UI fragments rendered as design elements, a recurring bracket or cursor mark, connected nodes.
- **Layout rhythm:** Product screenshots treated as hero objects (in device frames or floating with shadow). Feature trios broken up — never 4 identical card rows in a row.
- **Imagery:** Real UI, abstract architecture diagrams, atmospheric dark textures. Avoid generic "team collaborating".
- **Anti-patterns:** The classic AI template (centered hero → 3 cards → testimonials → pricing), violet gradient, fake dashboards with lorem numbers.
- **Vary by:** Light-vs-dark lane + motif (grid vs. node-network vs. bracket). A dev-tool deck and a CRM deck should feel different even though both are SaaS.

## Healthcare / Biotech / Medtech

- **Palette logic:** Clean, calm, credible. Soft neutrals + one trustworthy accent (clinical teal, deep green, warm coral for human warmth). Never cold sterile blue alone.
- **Type feel:** Humanist sans (or a humanist + clinical pairing). Readability and warmth over edge.
- **Motif idea:** Soft rounded shapes, a single organic curve, gentle data lines, a recurring molecular/pulse mark used sparingly.
- **Layout rhythm:** Whitespace = trust. Calm pacing. Human-impact slides interrupt the data with a real face/story.
- **Imagery:** Documentary lab/clinic environments, authentic human context, equipment close-ups. Never AI-generated faces; ask for real photos.
- **Anti-patterns:** Cliché stethoscope-on-keyboard, glowing blue DNA helix, "diverse team smiling in scrubs" stock.
- **Vary by:** Warmth dial (clinical-cool vs. human-warm) + accent. A biotech R&D deck leans cool/precise; a patient-facing health app leans warm/soft.

## Education / EdTech / Training

- **Palette logic:** Approachable and energetic without being childish. Warm off-white or one friendly primary + 1-2 supportive accents. Higher-ed leans more restrained than K-12.
- **Type feel:** Friendly rounded or clear humanist sans. Larger body sizes (this content gets projected and read from distance — 17pt+ body).
- **Motif idea:** Numbered steps, progress markers, a recurring "card with a soft shadow", highlight-marker underlines.
- **Layout rhythm:** One idea per slide, strong hierarchy for projection. High contrast. Quiz/checkpoint slides break the rhythm.
- **Imagery:** People learning/collaborating, spot illustrations for concepts, clear diagrams. Authentic over staged.
- **Anti-patterns:** Comic-sans energy, emoji as section icons, rainbow palettes, dense paragraphs in tiny type.
- **Vary by:** Audience age (K-12 playful vs. corporate-training restrained) + motif. Lecture decks and onboarding decks should diverge.

## Real estate / Construction / Architecture

- **Palette logic:** Material and grounded. Warm neutrals, stone, charcoal + one refined accent (terracotta, brass, deep green). Premium feels earthy, not flashy.
- **Type feel:** Editorial serif for premium, or strong geometric sans for modern/commercial. Big confident headlines.
- **Motif idea:** Full-bleed architectural photography, a thin frame/border line, a recurring grid, blueprint-line accents.
- **Layout rhythm:** Photography dominates. Big images, restrained text. Spec/data slides are clean and tabular.
- **Imagery:** Aerial site shots, architectural renders, material close-ups, real spaces. Always high quality and large.
- **Anti-patterns:** Tiny thumbnail images, generic city skyline, clipart house icons, cluttered spec tables.
- **Vary by:** Material mood (warm-earthy vs. cool-modern-concrete) + serif-vs-sans. A luxury residential deck ≠ a commercial development deck.

## Consumer brand / Retail / E-commerce / DTC

- **Palette logic:** Bold and ownable. Lead with the brand's actual colors; if none, pick ONE unexpected signature hue (terracotta, electric green, hot coral) and commit hard.
- **Type feel:** Expressive — a display face with personality + clean body. Type can carry the energy.
- **Motif idea:** Product-as-hero, big lifestyle imagery, a recurring shape/sticker/badge, oversized typographic statements.
- **Layout rhythm:** Energetic, varied, magazine-like. Product still-life alternates with lifestyle scenes. Big stats with attitude.
- **Imagery:** Product still life, lifestyle scenes, people genuinely using the product. Vibrant, not stocky.
- **Anti-patterns:** Corporate blue, flat text-only slides, tiny product shots, "happy customer" stock photos.
- **Vary by:** The signature hue + motif (sticker/badge vs. oversized type vs. full-bleed lifestyle). Each brand owns a different one.

## Energy / Climate / Sustainability / CleanTech

- **Palette logic:** Earth + energy. Deep natural base (forest, slate, deep teal) + one vivid energy accent (solar lime, amber, sky). Never the fintech blue.
- **Type feel:** Modern, grounded sans with weight contrast. Confident but not corporate.
- **Motif idea:** Horizon lines, a recurring energy/light gradient (atmospheric, not decorative), aerial-infrastructure imagery.
- **Layout rhythm:** Big atmospheric scene slides alternating with hard data. Scale conveyed through full-bleed environment shots.
- **Imagery:** Aerial infrastructure, real installations, documentary field shots, natural landscapes with the tech in them.
- **Anti-patterns:** Generic green leaf clipart, glowing blue "tech" abstractions, recycling-symbol cliché, stock wind-turbine-at-sunset.
- **Vary by:** Natural base hue (forest vs. slate vs. teal) + energy accent. A solar deck and a grid-storage deck should feel distinct.

## Legal / Consulting / Finance services / Professional

- **Palette logic:** Restrained authority. Near-white or deep navy base, near-black text, minimal accent (one muted tone used sparingly). Less is the whole point.
- **Type feel:** Refined serif (taste) or precise neutral sans (rigor). Generous tracking on labels. No flashy display.
- **Motif idea:** A single thin rule line, disciplined grid, subtle page system, restrained numerals. Quiet signature.
- **Layout rhythm:** Maximum whitespace, strict alignment, calm pacing. The restraint signals competence.
- **Imagery:** Sparse — abstract texture, a single strong photo, or clean data viz. Often image-light by design.
- **Anti-patterns:** Decorative gradients, accent overload, stock handshake, busy backgrounds, gold-everything "luxury" tells.
- **Vary by:** Serif-taste vs. sans-rigor + the single accent. A boutique advisory deck and a Big-4-style deck diverge sharply.

## Fashion / Luxury / Beauty / Lifestyle

- **Palette logic:** Editorial and high-contrast. Ivory/cream or rich dark base + a sophisticated accent (oxblood, gold, deep emerald). Monochrome elegance welcome.
- **Type feel:** High-contrast display serif (Instrument Serif, Radix) + minimal sans body. Type IS the design.
- **Motif idea:** Oversized editorial typography, generous margins, a single thin frame, full-bleed fashion imagery.
- **Layout rhythm:** Magazine spreads. Huge type, lots of air, one hero image per slide. Confidence through space.
- **Imagery:** High-fashion editorial photography, product still life, high-contrast texture, duotone treatments.
- **Anti-patterns:** Busy layouts, default blue, small type, clipart, more than one accent, anything that looks "techy".
- **Vary by:** Light-ivory vs. rich-dark base + accent (oxblood vs. gold vs. emerald). Each brand's editorial voice differs.

## Food / Hospitality / Restaurant / Travel

- **Palette logic:** Warm, appetizing, sensory. Warm neutrals + rich food-toned accents (terracotta, saffron, deep red, olive). Avoid cold tones near food.
- **Type feel:** Characterful — a warm serif or friendly display + clean body. Personality matters.
- **Motif idea:** Full-bleed food/place photography, a recurring menu-style divider, a hand-drawn or stamp accent.
- **Layout rhythm:** Photography-led and inviting. Big appetizing images, warm captions, generous plating space.
- **Imagery:** Beautiful plated-dish still life, atmospheric venue shots, genuine hospitality moments. Always make it look delicious.
- **Anti-patterns:** Cold blue palettes, tiny food thumbnails, generic "restaurant" stock, cluttered menu dumps.
- **Vary by:** Cuisine/venue mood (rustic-warm vs. refined-minimal) + accent. A street-food brand ≠ a fine-dining deck.

## Government / Infrastructure / Public sector / NGO

- **Palette logic:** Credible, accessible, solid. Restrained primary (deep blue, slate, deep green) + one clear accent. High accessibility/contrast is mandatory.
- **Type feel:** Clear, legible, neutral sans. Function over flair. Strong hierarchy for mixed audiences.
- **Motif idea:** A steady grid, aerial/map imagery, a recurring civic mark, clear iconography for wayfinding.
- **Layout rhythm:** Clear and methodical. Data presented transparently. One claim per slide, well-signposted.
- **Imagery:** Aerial maps, real field operations, engineering documentation, authentic community context.
- **Anti-patterns:** Over-designed flashiness, low-contrast text, decorative gradients, anything that reads as "salesy".
- **Vary by:** Primary hue + imagery focus (maps vs. field-ops vs. community). A transit-infrastructure deck ≠ an NGO impact report.

## When the topic isn't listed here

Don't force a fit. Instead, derive the DNA from first principles:

1. **What does the audience trust?** (restraint / boldness / warmth / precision) → sets palette + type feel.
2. **What is the subject physically made of?** → sets imagery type and motif (a logistics deck = movement/routes; a music app = waveforms/rhythm).
3. **What's the emotional payoff?** → sets the rhythm (calm-and-credible vs. energetic-and-bold).

Then write down a 6-line playbook in the same shape as above before building. Even an ad-hoc compass beats defaulting to dark-navy-and-one-accent for everything.

## Cross-cutting variation checklist (run before building any deck)

- [ ] Did I pick the SPECIFIC accent/base/font myself, not just copy the playbook's example values?
- [ ] If I've built for this industry before, does THIS deck differ in palette AND motif from the last one?
- [ ] Would the "brand swap" test fail? (Could I drop a competitor's logo in with no friction? If yes → not specific enough.)
- [ ] Is the motif a single committed signature, not three competing devices?
- [ ] Does the deck feel like THIS industry without looking like every other deck in it?
