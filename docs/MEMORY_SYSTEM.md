# Memory & Session System — Technical Design

## Overview

Every agent interaction generates session data that follows a lifecycle from full detail through summarization to eventual purge.

## Session Lifecycle

```
┌──────────────────┐
│ Active Session   │ ← Live conversation happening
│ Full detail      │
└────────┬─────────┘
         │ Session ends
         ▼
┌──────────────────┐
│ Session Storage  │ ← Supabase: sessions table
│ 7-day retention  │   Full conversation + memory.md
│ Full accessible  │
└────────┬─────────┘
         │ After 7 days
         ▼
┌──────────────────┐
│ Memory Database  │ ← Supabase: customer_memories table
│ 6-month retain   │   Summarized: name, contact, key details
│ Pertinent only   │   Used for lead gen, cold calls, texts
└────────┬─────────┘
         │ After 6 months inactive
         ▼
┌──────────────────┐
│ Purged           │ ← Permanently deleted
│ No recovery      │
└──────────────────┘
```

## Database Schema (Supabase/PostgreSQL)

### sessions
```sql
CREATE TABLE sessions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  agent_id UUID NOT NULL REFERENCES agents(id),
  customer_id UUID REFERENCES customers(id),
  
  -- Session metadata
  started_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  ended_at TIMESTAMPTZ,
  channel VARCHAR(50) NOT NULL, -- 'web_chat', 'phone', 'voice_chat'
  language VARCHAR(10) DEFAULT 'en',
  
  -- Conversation data (full detail)
  messages JSONB NOT NULL DEFAULT '[]',
  -- Each message: {role, content, timestamp, metadata}
  
  -- Memory file generated by agent
  memory_md TEXT, -- Agent's critical points summary
  
  -- Session state
  status VARCHAR(20) DEFAULT 'active', -- active, completed, escalated
  escalation_ticket_id UUID,
  
  -- Retention
  expires_at TIMESTAMPTZ, -- 7 days after ended_at
  summarized_at TIMESTAMPTZ, -- When moved to memory DB
  
  -- Indexes
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_sessions_agent ON sessions(agent_id);
CREATE INDEX idx_sessions_customer ON sessions(customer_id);
CREATE INDEX idx_sessions_expires ON sessions(expires_at) WHERE summarized_at IS NULL;
```

### customer_memories
```sql
CREATE TABLE customer_memories (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  agent_id UUID NOT NULL REFERENCES agents(id),
  customer_id UUID REFERENCES customers(id),
  
  -- Customer identification
  customer_name VARCHAR(255),
  customer_email VARCHAR(255),
  customer_phone VARCHAR(50),
  customer_company VARCHAR(255),
  
  -- Summarized memory
  summary TEXT NOT NULL, -- Condensed from session memory.md files
  key_details JSONB, -- Structured: preferences, past issues, purchases
  tags TEXT[], -- Searchable tags
  
  -- Lead generation data
  lead_score VARCHAR(20), -- hot, warm, cold
  interests TEXT[], -- Products/services they showed interest in
  last_interaction_at TIMESTAMPTZ NOT NULL,
  interaction_count INTEGER DEFAULT 1,
  
  -- Contact preferences
  contact_method VARCHAR(50), -- phone, email, text
  best_time_to_contact VARCHAR(100),
  do_not_contact BOOLEAN DEFAULT FALSE,
  
  -- Retention
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  purge_after TIMESTAMPTZ, -- 6 months after last_interaction_at
  
  -- Marketing use
  eligible_for_outreach BOOLEAN DEFAULT TRUE,
  outreach_history JSONB DEFAULT '[]'
  -- Each: {type: 'call'|'text'|'email', date, result}
);

CREATE INDEX idx_memories_customer ON customer_memories(customer_id);
CREATE INDEX idx_memories_agent ON customer_memories(agent_id);
CREATE INDEX idx_memories_purge ON customer_memories(purge_after);
CREATE INDEX idx_memories_lead ON customer_memories(lead_score) WHERE eligible_for_outreach = TRUE;
```

### customers
```sql
CREATE TABLE customers (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  
  -- Identification
  name VARCHAR(255),
  email VARCHAR(255),
  phone VARCHAR(50),
  company VARCHAR(255),
  
  -- Relationship
  first_contact_at TIMESTAMPTZ DEFAULT NOW(),
  last_contact_at TIMESTAMPTZ DEFAULT NOW(),
  total_sessions INTEGER DEFAULT 0,
  
  -- Status
  status VARCHAR(50) DEFAULT 'active', -- active, inactive, do_not_contact
  customer_type VARCHAR(50), -- prospect, customer, vip, employee
  
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE UNIQUE INDEX idx_customers_email ON customers(email) WHERE email IS NOT NULL;
CREATE INDEX idx_customers_phone ON customers(phone) WHERE phone IS NOT NULL;
```

### knowledge_bank
```sql
CREATE TABLE knowledge_bank (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  agent_id UUID NOT NULL REFERENCES agents(id),
  
  -- Content
  title VARCHAR(500) NOT NULL,
  content TEXT NOT NULL,
  content_type VARCHAR(50), -- 'document', 'webpage', 'faq', 'policy'
  
  -- Source tracking
  source_url TEXT,
  source_document VARCHAR(500),
  crawled_at TIMESTAMPTZ,
  
  -- Access control
  access_tier VARCHAR(20) NOT NULL DEFAULT 'public', -- public, customer, employee
  
  -- Approval workflow
  status VARCHAR(20) DEFAULT 'pending', -- pending, approved, rejected
  approved_by UUID,
  approved_at TIMESTAMPTZ,
  
  -- Metadata
  tags TEXT[],
  last_verified_at TIMESTAMPTZ,
  
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_knowledge_agent ON knowledge_bank(agent_id);
CREATE INDEX idx_knowledge_tier ON knowledge_bank(access_tier);
CREATE INDEX idx_knowledge_status ON knowledge_bank(status);
```

## Automated Jobs

### Session Summarization (Daily)
```
1. Find sessions WHERE ended_at < NOW() - INTERVAL '7 days' AND summarized_at IS NULL
2. For each session:
   a. Extract key customer details from memory_md and messages
   b. Create/update entry in customer_memories
   c. Mark session as summarized_at = NOW()
   d. (Optionally) archive full session data to cold storage
   e. Delete session messages (or mark for deletion)
3. Log results
```

### Memory Purge (Weekly)
```
1. Find customer_memories WHERE purge_after < NOW()
2. Verify no recent sessions exist for that customer
3. Delete purged records
4. Log purge event for compliance
```

### Lead List Generation (On-demand or Scheduled)
```
1. Query customer_memories WHERE:
   - eligible_for_outreach = TRUE
   - do_not_contact = FALSE
   - last_interaction_at > NOW() - INTERVAL '6 months'
   - lead_score IN ('hot', 'warm')
2. Return contact list with:
   - Name, phone/email
   - Last interaction summary
   - Interests
   - Recommended approach
3. Feed to automated outreach system (calls/texts)
```

## Memory.md Generation (Per Session)

The agent creates memory.md during/after each session:

```markdown
# Session Memory — {{timestamp}}

## Customer
- Name: [if provided]
- Contact: [phone/email if provided]
- Company: [if provided]

## Key Points
- [Critical detail 1]
- [Critical detail 2]
- [Decision or preference expressed]

## Issues/Requests
- [Issue raised and resolution status]

## Follow-up Needed
- [ ] [Action item if any]

## Tags
- [relevant tags for future retrieval]
```

The agent writes this based on what was actually important in the conversation — not a transcript, but critical intelligence.
